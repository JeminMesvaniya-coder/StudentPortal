# Student Portal

A Student Management System built using Spring Boot, Spring Data JPA, Thymeleaf, MySQL, HTML, CSS, and JavaScript.

## Features

* Add Student
* View All Students
* Search Student by ID
* Search Student by Name
* Update Student Details
* Delete Student
* Responsive User Interface
* MySQL Database Integration

## Technologies Used

* Java
* Spring Boot
* Spring Data JPA
* Hibernate
* Thymeleaf
* MySQL
* HTML5
* CSS3
* JavaScript
* Maven
* Git & GitHub

## Project Structure

StudentPortal
├── Controller
├── Service
├── Repository
├── Entity
├── Templates
├── Static
└── MySQL Database

## Database

Database: studentportal_db

Student Table Fields:

* id
* name
* email
* mobile
* course
* city

## How to Run

1. Clone the repository.
2. Open the project in IntelliJ IDEA.
3. Configure MySQL database in `application.properties`.
4. Run `StudentPortalApplication`.
5. Open the application in your browser.
